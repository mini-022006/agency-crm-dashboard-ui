# 💼 AgencyCRM Dashboard UI (UI/UX Case Study)

## 🔍 Project Overview
AgencyCRM is a modern CRM dashboard UI designed for digital marketing agencies to manage leads, active clients, revenue tracking, and daily follow-ups efficiently.

This project was created as part of Future Interns UI/UX Design Task 3.

---

## 🏢 Business Scenario
This CRM dashboard is designed for a 5-member digital agency handling multiple leads and clients simultaneously.

The system helps teams:
- Track lead progress
- Manage active clients
- Monitor revenue
- Handle tasks and follow-ups

---

## 🎯 Objective
- Simplify agency workflow
- Improve lead management
- Increase productivity
- Provide clear business insights

---

## 📊 Key Features
- Lead Pipeline Tracking
- Client Management
- Revenue Analytics
- Task & Follow-up Tracking
- Activity Overview
- Search & Quick Actions

---

## 🧠 UX Decisions
- Clean sidebar navigation for easy access
- Dashboard cards for quick insights
- Visual hierarchy for better readability
- Scalable layout for large data
- Minimal and modern SaaS-style UI

---

## 🎨 UI Style
- Modern SaaS dashboard
- Blue/Purple theme
- Card-based layout
- Responsive web dashboard design
  
---

## 🚀 Outcome
This dashboard improves workflow efficiency for agencies by centralizing lead tracking, client management, and analytics in one unified platform.
